## Автосалон «АвтоТрейд» — система управления автодилером

### Описание проекта

**АвтоТрейд** — современная система управления автосалоном, представляющая собой альтернативное решение для хранения и обработки данных без использования традиционных СУБД. Проект разработан для автоматизации работы автосалона, включая управление запасами, обработку заказов и анализ продаж.

### Основные потенциальные возможности

* **Клиентское приложение**:
  * Просмотр доступных автомобилей
  * Резервирование машин
  * Отслеживание статуса заказа
  * Поиск по моделям

* **Менеджерское приложение**:
  * Управление складскими запасами
  * Работа с закупочными ценами
  * Обработка заказов
  * Управление статусами автомобилей

* **Административная панель**:
  * Анализ продаж
  * Статистика по моделям
  * Отчеты по продажам
  * Управление каталогом

### Архитектура системы

Проект использует файловое хранение данных с обработкой через Python. Основные компоненты:

* **Модели данных**:
  * Автомобили (Car)
  * Модели машин (Model)
  * Сделки (Sale)
  * Статистика продаж

* **Структура данных**:
  * Индексные файлы
  * Основные данные
  * Исторические записи

### Технические требования

* **Язык разработки**: Python 3.10+
* **Основные библиотеки**:
  * Pydantic для валидации данных
  * Decimal для работы с ценами
  * Datetime для обработки дат
  * Enum для работы со статусами

### Функциональные возможности

* Управление статусом автомобилей (доступен/резерв/продан/доставка)
* Работа с VIN-кодами
* Обработка цен и дат
* Формирование отчетов по продажам
* Статистика по моделям
